## Общее описание

CLI-инструмент визуализации графа зависимостей
для менеджера пакетов .NET (NuGet).

На **этапе 1** реализованы:

- разбор шести настраиваемых параметров из опций командной строки
  (`--package`, `--repo`, `--test-mode`, `--version`, `--max-depth`,
  `--filter`);
- вывод всех параметров в формате `ключ=значение`;
- обработка ошибок для всех параметров.

На **этапе 2** реализованы:

- получение прямых зависимостей указанной версии пакета из NuGet
  (только стандартная библиотека, без менеджеров пакетов);
- если версия не задана, берётся свежая опубликованная;
- вывод прямых зависимостей на экран.

На **этапе 3** реализованы:

- построение графа поиском в глубину с рекурсией;
- учёт максимальной глубины и пропуск пакетов по подстроке фильтра;
- корректная обработка циклов (выводятся, обход завершается);
- тестовый режим: граф читается из файла вида `A: B C`.

На **этапе 4** реализованы:

- вывод обратных зависимостей пакета (кто зависит от данного,
  прямо или через цепочку) тем же поиском в глубину;
- сравнение со штатными средствами (`nuget list`, дерево зависимостей
  в обозревателе NuGet): состав совпадает, расхождения возможны
  в опциональных зависимостях и сортировке.

На **этапе 5** реализованы:

- текстовое описание графа на языке диаграмм Mermaid (`graph TD`,
  стрелки `A-->B`) и вывод его на экран;
- примеры визуализации для трёх пакетов — ниже в разделе
  «Примеры использования»;
- сравнение со штатными средствами (`nuget list`, обозреватель
  пакетов NuGet): состав рёбер совпадает, расхождения — только
  в оформлении.

## Примеры использования

Визуализация графа из тестового файла:

```sh
PYTHONPATH=src python3 -m depgraph --package A \
  --repo tests/testdata/branch.txt --test-mode on
```

Вывод содержит порядок обхода, обратные зависимости и Mermaid-описание:

```text
graph order:
  A
  B
  D
  C
reverse deps:
  A
mermaid:
graph TD
    A-->B
    A-->C
    B-->D
    C-->D
```

Циклический граф:

```sh
PYTHONPATH=src python3 -m depgraph --package A \
  --repo tests/testdata/cycle.txt --test-mode on
```

Линейная цепочка:

```sh
PYTHONPATH=src python3 -m depgraph --package A \
  --repo tests/testdata/chain.txt --test-mode on
```
